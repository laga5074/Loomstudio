# Chrome Extension - Web & Screen Capture Pro 📸

This Chrome Extension allows you to take screenshots on **ANY tab while browsing**:
1. **🖥️ Viewport Screenshot**: Captures what is currently visible on screen.
2. **✂️ Select Area with Mouse**: Drag a rectangle anywhere on the webpage to crop & download a region.
3. **📜 Full Page (Tall Image)**: Auto-scrolls the entire long webpage and stitches it into a single tall PNG image.

---

## How to Install in Chrome / Edge / Brave Browser:

1. Download or copy the files in this folder (`chrome-extension/`).
2. Open Google Chrome and navigate to `chrome://extensions/`
3. Toggle on **"Developer mode"** in the top-right corner.
4. Click **"Load unpacked"** in the top-left corner.
5. Select the `chrome-extension` folder.
6. The extension icon will appear in your Chrome extensions bar! Pin it and click whenever you browse any website to capture screenshots!
